# Sort my Media

Turns a messy pile of photos, videos and sounds into clear folders. Claude looks at every file, even listens to the sounds, and suggests where each one goes. You check the plan before anything moves, and you can put everything back with one click. Your files stay on your Mac. Claude only sees small previews, the file names and short text clues (for example the first 30 seconds of speech, turned into text on your Mac), through your own Claude plan.

**Install guide (PDF):** every step with pictures, two routes (Terminal or the Claude desktop app): [install_guide.pdf](install_guide.pdf). Also in [AI Lab](https://github.com/duduexe/ai-lab/tree/main/08_sort_my_media_install).

## What you need
- A Mac.
- A Claude plan that includes Claude Code (Pro, Max, Team or Enterprise). No API key.
- The Claude desktop app (claude.com/download), signed in. You do not need to know the Terminal.

## Get it
- Press the green **Code** button on this page, then **Download ZIP**. Open the zip and move the folder into your home folder (for example `/Users/yourname`).
- Or let Claude do it: in the Claude desktop app, go to **Code**, choose your home folder and paste:
  > Download Sort my Media from https://github.com/duduexe/sort-my-media into my home folder, then set it up by following its SETUP.md. Ask me before you install anything.

## Set it up (about 10 to 30 minutes)
1. Put this folder in your home folder (skip if Claude downloaded it).
2. Open the Claude desktop app and go to **Code**. Choose this folder as the folder to work in.
3. Paste this and press Enter:

   > Set up Sort my Media by following SETUP.md. Ask me before you install anything.

4. Claude checks your Mac, asks before each install, and guides you through one short sign-in in a Terminal window it opens for you (Sort my Media needs that to talk to Claude by itself).
5. At the end, open **Sort my Media** from your Desktop or Applications.

Already use Claude Code in the Terminal? Open a Terminal in this folder, type `claude` and paste the same sentence.

Help inside the app: press **Guide**, then **How to set up**.
